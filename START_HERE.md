# START HERE — Clinic Management System

This folder is the complete handoff package for OpenCode.

## Your job
Build the complete production-ready clinic management system described in `docs/BLUEPRINT_AR.md`.

Do **not** wait for the owner to manually break the work into tasks. You are the implementation agent. Read the full blueprint, create a plan, build the app end-to-end, run migrations, seed demo data, run tests, fix failures, and leave the repository runnable and documented.

## Read in this order
1. `AGENTS.md`
2. `MASTER_PROMPT.md`
3. `docs/BLUEPRINT_AR.md`
4. `ACCEPTANCE_CRITERIA.md`

The original formatted Arabic blueprint is also available at `docs/BLUEPRINT_AR.docx`.

## Critical rule
Business requirements marked **TBD** in the blueprint are not permission to invent clinic policy. Implement them as disabled/configurable features or safe placeholders, while continuing with everything else.
